# 前端可回退功能开关

> 用途：记录可能撤销的 UI 改动及最小回退方法。  
> 日期：2026-10-26

## 1. Sessions 侧栏 Provider 彩色圆点

功能标识：

```text
provider-dots
```

代码搜索锚点：

```text
FEATURE_ROLLBACK_ANCHOR: provider-dots
data-feature="provider-dots"
FEATURE_PROVIDER_DOTS
```

当前颜色：

- Codex：绿色。
- VS Code：蓝色。
- Copilot CLI：黄色。
- 未知 Provider：灰色。

快速撤销：在 `frontend/index.html` 中把下面的值改成 `false`：

```javascript
const FEATURE_PROVIDER_DOTS=false;
```

这会隐藏圆点，但保留侧栏原有来源文字和所有数据字段。完整移除时，可按上述锚点删除
圆点 CSS、DOM 和 gate，其他会话逻辑不受影响。

## 2. Agent 内容宽度模式

功能标识：

```text
content-width-modes
```

代码搜索锚点：

```text
FEATURE_ROLLBACK_ANCHOR: content-width-modes
data-feature="content-width-modes"
FEATURE_CONTENT_WIDTH_MODES
```

三档宽度：

| 模式 | 行为 |
|---|---|
| Narrow | 原始 `960px` 最大正文宽度 |
| Medium | 最大正文宽度 `1240px` |
| Full | 填满 Sessions 和 Outline 之外的剩余空间，左右保留 `28px` |

宽度按钮与 `1 column / 2 columns / 3 columns` 布局控件放在同一组中，按钮只显示
`Narrow`、`Medium` 或 `Full`，不显示 `Width:` 前缀。

当前模式保存在浏览器：

```text
localStorage.contentWidthMode
```

快速撤销：把下面的值改成 `false`：

```javascript
const FEATURE_CONTENT_WIDTH_MODES=false;
```

按钮会隐藏，页面恢复 Narrow。完整移除时，按锚点删除宽度 CSS、按钮、状态变量和函数，
并可清理 `localStorage.contentWidthMode`。
